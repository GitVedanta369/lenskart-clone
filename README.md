# Lenskart — Modern Online Eyewear Shopping Platform Clone

A modern, pixel-perfect e-commerce shopping experience inspired by **Lenskart.com**, built strictly using **100% Pure HTML5 & CSS3** (zero JavaScript).

## 👓 Highlights & Features
- **Authentic Hero Slider:** Widescreen desktop campaign banners with smooth next/prev controls and indicator dots.
- **Category-Driven Sub-Sections:** Interactive category switcher (Men, Women, Kids, Sunglasses, Screen Glasses, Contact Lenses) showcasing dedicated subcategories and shapes.
- **4-Column Responsive Grid View:** Handcrafted product cards featuring ratings, 3D Try-On badges, color swatches, and real pricing.
- **Interactive Pure CSS Cart Drawer:** Real-time **Add to Cart**, **Remove**, and **Quantity Stepper (+ / -)** with dynamic CSS counter badge updates and empty-state handling.
- **Interactive Pure CSS Wishlist Drawer:** Tap the heart icon to save favourites, view in a dedicated slide-out drawer, and move items directly to Cart.
- **Zero JavaScript:** Built entirely on CSS pseudo-classes, sibling combinators (`~`), and CSS counters.

## 🚀 How to Run
Simply open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari). No build tools, package managers, or server setup required.
